# QSkill Internship Tasks

A collection of hands-on **Python and Machine Learning projects** completed during my QSkill internship, focused on implementing end-to-end data processing, predictive modeling, visualization, and model evaluation workflows.

## 🚀 Projects

### 1. Iris Flower Classification

A supervised machine learning classification project that predicts the species of an Iris flower from its sepal and petal measurements.

**Problem:**  
Given flower measurements such as sepal length, sepal width, petal length, and petal width, classify the flower into its corresponding Iris species.

**Key Work:**
- Loaded and explored the Iris dataset.
- Performed data analysis and visualization to understand feature distributions.
- Prepared the dataset for machine learning.
- Built a classification model using **Scikit-Learn**.
- Evaluated model performance using appropriate classification metrics.
- Created visualizations to understand the dataset and model results.

**Technical Concepts:**
- Supervised Learning
- Classification
- Feature Analysis
- Data Visualization
- Model Evaluation

---

### 2. House Price Prediction

A supervised machine learning regression project that predicts house prices based on available housing features.

**Problem:**  
Use property-related features to estimate the expected price of a house.

**Key Work:**
- Loaded and analyzed the housing dataset.
- Performed exploratory data analysis to understand feature relationships.
- Prepared numerical features for modeling.
- Applied **feature scaling** where required.
- Built a regression model using **Scikit-Learn**.
- Evaluated predictions using regression evaluation metrics.
- Compared predicted values with actual values to understand model performance.

**Technical Concepts:**
- Supervised Learning
- Regression
- Feature Scaling
- Data Analysis
- Model Evaluation
- Predictive Modeling

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/aeldrift/Qskill_internship_tasks.git
cd Qskill_internship_tasks
```

### 2. Create a virtual environment

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the project

Navigate to the respective task directory and run the Python script/notebook provided for that task.
